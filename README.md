توسعه‌دهنده‌ی فول‌استک وب با تمرکز روی React، PHP و وردپرس هستم.  
با علاقه زیاد به توسعه رابط‌های کاربری مدرن، پلاگین‌نویسی وردپرس، و ساخت سیستم‌های قابل مقیاس، هم در فرانت‌اند و هم در بک‌اند تجربه دارم.
